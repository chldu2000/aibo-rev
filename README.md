# aibo-rev

终端优先的 Aibo 新方向：保留各 Agent 的原生 CLI，以跨 Agent 引用原始 transcript 为核心，提供会话列表，并为 Git、文件浏览等工作台面板保留扩展空间。

本仓库保存 2026-11-01 讨论形成的设计、决定和待验证问题，尚未包含产品实现。创建本仓库不表示批准全面重构，也不预先确定 Ghostty、xterm.js、ACP 或桌面框架选型。

## 阅读入口

- [领域词汇](CONTEXT.md)：会话、原始 transcript、引用与摘录的含义。
- [设计提案](docs/design.md)：候选架构、使用流程与验证计划。
- [已确认决定](docs/adr/0001-terminal-transcript-references.md)：本轮已达成的取舍。
- [讨论记录](docs/discussion.md)：讨论如何从完整平台简化转向终端路线，以及哪些尚未定案。
- [原仓库未提交文档补丁](docs/archive/aibo-design-changes.patch)：迁入前的原始文档证据，不含代码或个人配置改动。

## 与原仓库的关系

此前“保留完整插件平台与管理中心、简化内部机制”的提案已提交在 `aibo` 的 `docs/lightweight-architecture-proposal` 分支，提交为 `de70665`。它是前一条候选路线，不能把其中所有产品范围要求自动继承为本仓库的目标。

本仓库独立记录随后尚未提交的终端路线，并补入最后一轮已确认的摘录及输入交付决定。原仓库的工作区改动保持原样；这里的归档补丁是证据副本。当前设计以本仓库的决定和提案为准，旧补丁中的“尚待确定”可能已被本轮回答解决。

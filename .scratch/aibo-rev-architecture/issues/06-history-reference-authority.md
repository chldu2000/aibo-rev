## Question

离线历史阅读已经选中；离线或不可用来源的引用尚未选中，不能混作同一承诺。原生续接状态也不等于可跨 Agent 传递的历史。

### 来源与业务历史

Aibo 自己持有的用户输入、附件及引用关系，与通过 ACP 获得的消息、工具和任务内容共同组成业务历史。未发送的草稿和队列内容属于输入及恢复状态，不能作为来源会话已经发生的对话分享；投递结果未知的记录须保留其不确定性，不能假称 Agent 已接收。

统一表示应保留取得的原文、角色、顺序、工具/任务关联和来源线索，使展示、搜索与引用能定位同一内容。用于界面展示的摘要、索引和排版均是派生表示，不能反过来替换原文。此处确定内容权威，不要求永久保存每个流式分片、重复协议快照或诊断包。

ACP 可观察历史与原始 Transcript 保持两个术语。无法取得 Agent 原生格式的文件不阻止基于已保存原文的引用；也不暗示 Aibo 已捕获未公开消息、隐藏状态或全部原生元数据。原生会话能否恢复，继续由 Agent 能力和恢复合同决定。

重新加载或补读历史不能把原生压缩后的结果当作覆盖旧记录的指令；需要核对身份、版本和来源，避免重复导入或把不同内容误合并。具体去重与存储机制归数据所有权票。

### 固定版本与完整性

一次引用须固定来源身份、实际捕获范围、内容版本、完整性说明，以及纳入的子任务和附件成员。边界是 Aibo 当时已保存的内容，不宣称是多个原生执行过程在同一时刻的完整快照。

已固定版本不随来源继续生成、原生重载或后台补读改变。用户主动更新引用时建立新的版本关联；已发送记录仍保留原先使用的版本。正在生成的消息可以作为未完成内容纳入，之后完成的结果不能写回旧引用。

“全文”指该版本实际保存的完整范围：

- 主会话原文与相关工具记录按稳定顺序提供；已知缺口和截断明确可见，不以空内容或成功状态掩盖。
- 子 Agent 和后台任务只纳入具有明确来源关系且已保存的记录；各成员有固定内容边界。引用后新增的任务、消息和输出不自动加入。
- 已保存附件按固定内容读取；路径记录只证明当时存在这项引用，不能代替文件字节，也不能授权读取任意当前路径。
- 来源历史里曾引用另一会话，不自动授予读取那一会话全文的权限。已经出现在来源记录中的摘录仍属于该记录；进一步读取其他版本需要独立的显式引用。

摘录是固定内容的选择，不是生成摘要。截取应保留角色与工具关联，标明省略位置及同版本读取入口；选择附带全文仍须遵守可用发送能力与大小限制。接收 Agent 不支持全文工具或某种附件内容时，明确说明可用范围，不伪造可调用入口，也不因缺少 MCP 就取消基础文本引用。

### 读取授权与保留

固定版本、引用读取授权和投递状态是不同事实：加入草稿时可以固定内容，但不因此把未发送内容暴露给正在运行的接收 Agent。读取授权须绑定接收会话、引用版本和允许的关联资源；启用时点、失败及结果未知的处理，与实际投递合同在会话控制票中确定。

工具读取应核对调用者与引用范围，并能按稳定内容标识分页；翻页不能切换到来源的最新内容。版本缺失、资源未保存、调用者无权访问或能力不可用须明确返回，不能退回读取当前文件来凑出“全文”。接收侧子 Agent 是否通过父会话委托读取，以及如何识别调用者，须在后续运行合同中明确，不能默认扩大授权。

固定内容只要仍被草稿、队列或已发送历史引用，就属于受保护数据；来源归档、插件卸载和原生数据消失均不能令其失效。草稿中的保留关系不等于接收 Agent 已获得读取权限。

解除某个引用关联不代表内容可立即删除：还需检查其他引用、业务历史与未决投递责任。固定版本可以复用已保存的不可变内容，不要求每次复制整棵历史及全部附件；物理存储、共享内容计数、预算和回收方式由数据所有权票确定。本票不新增永久删除界面，也不将用户手工删除存储文件后的可读性当作保证。

### 范围与后续验收

同工作区引用、离线及归档历史阅读、插件不可用后的历史阅读仍按 Checklist 交付。已有引用的持续可读性与“从已归档或提供者不可用的来源新建引用”不同，后者仍未纳入；跨工作区引用也仍未纳入。纳入子任务及附件的按需读取，不自动增加工具输出/子历史搜索、附件搜索或文件浏览器功能。

最终验收至少覆盖以下场景：

| 场景 | 应证明的结果 |
| --- | --- |
| 加入引用后，来源继续生成，目标消息等待排队 | 摘录与各页全文仍是加入时的版本；主动更新才纳入新内容 |
| 原生历史被压缩或清理，来源插件卸载 | 已保存历史可读，已有引用可按授权读取；未承诺的新建引用范围不被扩大 |
| 捕获未完成消息或存在已知缺口 | 缺口可见，后续补齐不修改旧引用，不把已保存范围称为完整原生记录 |
| 子任务产生新输出，原附件路径内容变化 | 读取固定成员版本及已保存附件；不补入后来的输出或当前磁盘内容 |
| 草稿尚未发送，或另一会话尝试读取版本 | 固定内容可以保留，但未获得对应授权的调用不能读取；无隐式全工作区或递归引用权限 |
| 多条引用复用内容，或队列投递结果未知 | 取消一项关联不破坏其他有效引用或未决操作；保留规则与投递证据一致 |

# Windows 人工验收确认

日期：2026-11-12。来源：本轮用户直接反馈。

> 人工验证通过；ADR 0008 恢复策略可以按照建议修订

该确认对应 17 号票交给用户的人工清单：原生界面字体/缩放、输入法、粘贴/拖放、文件与目录选择器、深浅色、标题栏与贴靠；面板焦点、快捷键、输入法、故障恢复；托盘关窗重开与通知定位；讲述人；Mica 与关闭透明效果。

证据类型为用户手动操作反馈。用户未逐项附加第三方输入法名称/版本、显示器型号、通知是否使用安装版等详情，这些详情不作推定。

用户同时授权接受 ADR 0008：无响应时重建单个面板；共享浏览器退出时重建全部受影响面板；保留原生工作台、包进程与会话执行，不用 Page.ProcessID 结束单个面板。

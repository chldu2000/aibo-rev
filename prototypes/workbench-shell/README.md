# 工作台外壳原型（macOS）

一次性实验，不是产品实现。回答 [18 号票](../../.scratch/aibo-rev-architecture/issues/18-macos-workbench-shell-validation.md)：ADR 0006 与界面方案 §15 中不依赖 Windows 的未验证项。基于 [`native-ui`](../native-ui/README.md) 复制（`model.go`、`view.go`、`tokens_gen.go`），未改动作为验收目标的 `native-ui`。

## 运行

```sh
CGO_ENABLED=0 go test ./...                                    # 无窗口检查
CGO_ENABLED=0 go build -o bin/shell . && ./bin/shell           # 直接运行（关窗 = 销毁窗口）
./bin/shell -close hide                                        # 关窗 = 隐藏窗口
./bin/shell -auto reports/auto-destroy.json                    # 真实窗口自动检查，约 25 秒
./bin/shell -close hide -auto reports/auto-hide.json
CGO_ENABLED=0 go tool mygo build -skip-dmg                     # 打包 dist/darwin-arm64/Aibo Shell Prototype.app（通知须打包）
open "dist/darwin-arm64/Aibo Shell Prototype.app" --args -log "$PWD/reports/manual.log"
```

| 文件 | 内容 |
| --- | --- |
| `shell.go` | 外壳：多会话切换（交换当前会话字段）、`ui.Split` + `ui.WebView` 工具面板、区域级故障边界 `guard`、故障注入、隐藏标题栏拖动区 |
| `main.go` | 窗口创建/重开、`aibopkg://` 包协议、托盘与“验证”菜单、通知与点击定位 |
| `auto.go` | 真实窗口自动检查 |
| `shell_test.go` | 无窗口检查（`ui.Tester`） |
| `panel/panel.html` | 模拟工具面板：100 ms 计时器、输入框、按键与焦点日志 |

## 结果（2026-11-12，macOS 27 arm64，MyGO v0.9.0，Go 1.27.3）

### 区域级 panic 边界：可行

做法：在区域外层元素的 `Children` 闭包里 `defer recover()`。MyGO 的 `node.Children` 不用 `defer` 恢复父节点，但外层 `Children` 在闭包正常返回后会把父节点恢复到自己保存的值，所以内部嵌套元素留下的父节点指针能被外层纠正。recover 之后记录故障并 `Invalidate`，下一帧改为显示故障说明与“重试”按钮。

| 检查（`go test`） | 结果 |
| --- | --- |
| `ui.List` 行内、`Collapsible` 内的工具卡 panic | 只有该条显示故障；其他条目、审批按钮、输入照常；重试后恢复 |
| `Overlay`（候选弹层）内 panic | 输入区显示故障；重试后输入区恢复、草稿仍在；之后队列浮层（另一个弹层）正常打开 |
| 侧栏与工具面板整区 panic | 两区显示故障，会话区与输入照常 |
| 真实窗口注入侧栏 + 工具卡 panic | 两处隔离，界面继续构建，草稿可编辑 |

限制：
- panic 发生的那一帧，区域内已构建的部分元素仍会显示一次，下一帧才换成故障说明。
- `Element.Children` 在有主题作用域（`themed`）时也不用 `defer` 恢复主题；原型的区域内没有主题作用域。产品实现中，故障边界不能放在会切换主题的元素内部，或者边界自己重新设置主题。
- 只能拦截视图构建中的 panic。事件回调（`OnClick` 等）与 goroutine 中的 panic 不经过这里，要另外处理。

### 同一窗口中的工作台与工具面板 WebView：可行

| 项目 | 结果 |
| --- | --- |
| 进程 | 应用 21973，面板 WebContent 21977：独立进程 |
| 分隔条 | 面板宽 360/480 时，页面 `innerWidth` 为 358/478（少 2 DIP，推测为面板左边框与分隔线）；窗口从 1280 加宽到 1500，面板仍为 478，会话区变宽 |
| 键盘焦点 | `WebView.Focus()` 后 `document.hasFocus()` 为 true；页面内输入框可以获得焦点 |
| 收起 3 秒再展开 | 页面保留（`loadedAt` 不变，输入框焦点位置保留）；**收起期间页面计时器被系统大幅节流**：3 秒只走了 5 次（正常为 30 次），展开后恢复 |
| 面板死循环时的工作台 | 流式 108 帧，发布→构建平均 4.3 ms、最长 5.6 ms；界面线程延迟平均 0.63 ms、最长 3.1 ms |
| 死循环恢复 | `Eval` 1.5 秒超时 → 结束渲染进程 → `Reload`，约 100 ms 后页面可用（含超时共 1.9 s） |
| 结束面板渲染进程 | `OnRenderProcessGone("terminated")`，工作台界面线程最长 0.09 ms；`Reload` 约 0.4 s 恢复 |

### 关闭最后一个窗口后重新打开

两种关窗方式都会让应用留在后台；宿主持有的界面状态都能恢复：所选会话、草稿、面板宽度、会话流滚动位置（首个可见条目 5 → 5）。区别在工具面板页面：

| 方式 | 面板页面 | 隐藏期间计时器 |
| --- | --- | --- |
| 销毁窗口（`-close destroy`） | 随窗口销毁，重开后重新载入（计数清零） | — |
| 隐藏窗口（`-close hide`） | 保留（`loadedAt` 不变） | 约 3.5 秒走了 20 次，约为正常的 57% |

键盘焦点与文字选区不在宿主状态中，视图重建后不恢复（`Tester` 中重建后输入框未获得焦点）。

### 对 F17.5（隐藏工具视图后保持后台运行）的含义

不论是收起面板还是隐藏窗口，WKWebView 都会节流页面计时器；销毁窗口则页面直接结束。因此能力包的后台工作必须放在包的进程（MCP 服务等）里，面板页面只做展示，重新打开时从包进程取回状态，不能依赖页面里的 JS 持续运行。这与 ADR 0005 的工具面板装载方式一致，但需要在 ADR 或 09 号决议中写明。

## 手动验证

2026-11-12 用户用打包后的 `.app` 按下列清单检查后表示没有问题，并决定关闭最后一个窗口时销毁窗口。清单：

1. **标题栏**：交通灯不压住侧栏内容；拖动侧栏顶部、会话区标题行和面板标题行可以移动窗口；双击会缩放窗口；标题行里的按钮可以正常点击，不会触发拖动。
2. **焦点往返**：在输入框按 Tab 能进入面板、再移出；点击面板后再点输入框，键盘回到原生 UI；面板有焦点时按 ⌘\ 能收起面板（按键从页面传到原生 UI）。
3. **面板内中文输入法**：在面板的多行输入框里输入中文，候选窗位置正确，确认候选时按 Enter 不触发其他操作。
4. **故障**：用面板“…”菜单让页面卡死，工作台仍能输入和滚动，点“重新载入”恢复；用“故障注入”菜单让各区域 panic，再点“重试”。
5. **通知**：菜单栏“验证 → 8 秒后发送审批通知”，然后切到别的应用（或先切到“ACP 连接层”会话再关窗口）；首次会请求通知权限；点击通知后，窗口打开、切到“修复队列暂停逻辑”并滚动到新的审批卡。
6. **VoiceOver**（⌘F5）：依次朗读侧栏会话、会话内容的“用户消息/Agent 回复”分组、输入框“消息”、禁用的“发送”及原因、面板网页内容、分隔条。
